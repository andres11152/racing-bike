Modales/popups enterprise con captura de suscriptores, triggers avanzados, segmentación, A/B testing e integraciones.

== Description ==

Skycode Modal Pro gestiona campañas de modal ilimitadas, cada una con sus propios triggers (retraso, scroll, exit intent, inactividad, número de páginas, clic en selector), reglas de segmentación (página, dispositivo, rol, estado de sesión, primera visita, UTM), control de frecuencia por visitante, variantes A/B y webhook de integración genérico compatible con Zapier/Make/n8n y la mayoría de ESPs.

== Installation ==

1. Sube la carpeta `skycode-modal` a `/wp-content/plugins/`.
2. Activa el plugin desde el panel de WordPress.
3. Ve a "Modal Pro" en el menú de administración para crear tu primera campaña.
